# CPU-Scheduling-Algorithms-Simulations

A comprehensive Python implementation and analysis of five fundamental CPU scheduling algorithms used in operating systems. This project provides detailed performance comparisons across multiple test scenarios.
📋 Overview
This simulator implements and analyzes the following CPU scheduling algorithms:

FCFS (First-Come First-Served) - Non-preemptive, simplest scheduling
SPN (Shortest Process Next) - Non-preemptive, also known as SJF
SRT (Shortest Remaining Time) - Preemptive version of SPN
Round Robin (RR) - Preemptive with time quantum
Priority Scheduling - Non-preemptive, priority-based

🎯 Features

Complete implementation of 5 scheduling algorithms
Gantt chart visualization for process execution
Performance metrics calculation:

Average Wait Time
Average Turnaround Time
Average Response Time


Five comprehensive test cases covering different scenarios
Comparative performance analysis with visualizations
